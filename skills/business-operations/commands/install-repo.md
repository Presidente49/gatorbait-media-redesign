---
name: install-repo
description: Install or activate one explicitly selected repository using its own documented method after source, host and scope checks.
disable-model-invocation: true
---
Read references/repository-intake.md and the selected catalog/repos.json row. Inspect the original source instructions and current host installation first. The owner must identify the target component and host; resolve them from authorized context when available. Do not batch-execute the catalog or substitute wrappers for original software. Follow upstream prerequisites and one supported method, preserve approvals and record deviations. Installation remains open until actual host discovery and harmless workflow verification pass with a real receiving-stage acknowledgment. Missing host access is a blocker, not permission to install into another machine or client.
