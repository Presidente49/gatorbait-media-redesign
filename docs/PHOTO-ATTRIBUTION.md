# Photo attribution (Brenden, Oct. 18, 2026)

UAA's biggest concern is attribution, so we go further than required. This applies to every UAA / UF photo (Hannah White and any other UF photographer) on the site, in email, in the magazine and on social.

1. **Credit text:** "Photo courtesy UAA and <verified photographer name>." Use the photographer named in the file (for example `261017_Texas_FB_11098_HannahWhite.jpg`). Never crop, cover or strip a credit.
2. **Link both credits.** UAA links to https://floridagators.com. The photographer links to their own page when one exists (Hannah White: https://www.instagram.com/hannahmorganphoto/). Add a courtesy link to UF's official galleries (https://floridagators.com/galleries, or the game's gallery once UF posts it).
3. **Site stories:** credit in the cover/image alt text, plus a visible closing line naming the actual photographer: "Photo courtesy UAA (University Athletic Association, FloridaGators.com) and <verified photographer name>. See the photographer’s verified page and the official Florida Gators photo galleries at FloridaGators.com." Link UAA, the verified photographer page when available, and the game gallery. Do not substitute Hannah White or another default name for the actual credit.
4. **Email and magazine:** credit in the alt text and a linked "Photo credits" block (email) or a caption on each photo plus the footer (magazine).
5. **Social shares:** the credit is on the image itself (small line, bottom corner) and in the caption text: "Photo courtesy UAA and <verified photographer name> (floridagators.com)", plus a link to floridagators.com/galleries where the platform allows links. Tag the account only if the handle is verified.
6. We do not host a GatorBait gallery of UAA photos. We link to theirs.
7. Get the photo from UF's own pages (recap page or gallery), import it into Wix Media Manager, set alt text with the credit, and record the source in #34.

## Current-game art gate (Brenden / Marlo, November 8, 2026)

Effective immediately, every desk and publishing lane must verify art before publication or promotion:

- Article lead images, covers, Open Graph/Twitter images, magazine covers and promos for current coverage must come from the current game/week. Prior-opponent photos are banned, including the September 26 Ole Miss game. A visible credit does not make stale art acceptable.
- If no fresh still exists, extract an authentic frame from current-game/current-week video. Preserve the video source and timecode. Do not fabricate a game photograph or present an enlargement as newly recovered detail.
- Verify the pictured person, actual event/opponent and capture date from the photographer, Brenden's explicit identification, or an official caption. A filename, jersey number or visual guess alone is insufficient. Never change a caption to make the wrong person or setting fit the assignment.
- Before writing, record the source URL or original-file hash, game/date, photographer credit, production Wix media ID and dimensions. Store assets in `MEDIA / ARTICLES / YYYY / MM-MMM / YYYY-MM-DD <Story Name>`; do not hotlink temporary assets.
- For a content image, use Wix’s native image caption field (`imageData.caption`) and keep alt text separate. A body-text photo credit does not replace the image caption. Keep the required linked closing credit as attribution.
- Do not repeat a photo across stories visible together on the homepage.
- Change the article image, visible caption, alt text, cover and explicit OG/Twitter overrides together. Remove the superseded photo/caption from the article. Preserve filed prose, author, first publication, slug and access.
- Re-read live and draft state first. One writer owns each object. If another lane has unpublished changes, reconcile the exact diff rather than publishing those changes incidentally.
- Verify the canonical public article, rendered caption, cover and OG/Twitter image after publishing. Record before/after post and media IDs plus source/date/credit in the receipt. An API success alone does not prove the public preview changed.
- Historical articles remain records of their own event; do not relabel an old photograph as current. Featuring or promoting a historical story in a current package must pass this current-week art gate. A historical-subject exception requires an explicit owner instruction.

This gate supersedes older guidance allowing generic file photos for current coverage. Credit requirements above still apply. A missing requested asset is reported plainly; use only a verified, accurately captioned current-week alternative while obtaining it.
