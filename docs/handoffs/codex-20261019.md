## Lessons learned (these cost us time)
- Container Chromium cannot reach gatorbaitmedia.com or ESPN. Use the read-only GitHub Actions Playwright probe on a `probe/` branch (never disable TLS verification), TinyFish `fetch_content` sparingly (wallet is low), and ESPN's JSON directly when reachable.
- Several Claude agents sharing one checkout put commits on each other's branches and trip the stop hook. Use a separate worktree per task and leave other agents' uncommitted files alone.
- Running six or more agents at once hit the API session limit and killed all of them. Keep to two or three at a time, and give each a narrow brief.
- Old stories on the front page came from native blog lists (All News and categories) where manual pinning/featured order put old posts on top, not from the homepage loader (which sorts the feed by date, uncached). Never pin or reorder posts.
- Wix email: classic-editor drafts cannot be edited (create a replacement campaign); a sent email cannot change; send-governor caps are 1 list email per 24 h and 7 per week; the account rank reads BAD in Wix (informational).
- Gmail groups test sends into one thread: open the later message.
- Embeds cannot run on the 404 page; /shop is the ItemOrder store; login, member dialogs and checkout are Wix-owned. Do not "fix" them with CSS.
- WebKit emulation has no Safari toolbar collapse or safe-area inset: anything iPhone-specific still needs Brenden's real phone. State plainly what was not verified.
- The permission classifier can block a git fetch ("External System Writes"). Do not work around it; tell Brenden to allow it.
- Wix `PATCH` on embeds needs the current revision and ESSENTIAL re-sent; re-read before every write.
