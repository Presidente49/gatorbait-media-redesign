# GatorBait Studio Product Architecture

## Build sequence

Research -> Inventory -> Site map -> Route matrix -> Wireframes -> Design system -> Components -> High-fidelity prototypes -> Motion spec -> Studio branch build -> Data/app wiring -> Migration rehearsal -> QA -> Approval -> Cutover

## Shared navigation

Primary:
- News
- Recruiting
- GatorBait TV
- Magazine
- GatorBait.net
- Shop

Utility:
- Search
- Watchlist / Saved
- Subscribe / Join
- Account

## Page families

### Front Page
- masthead
- lead story
- secondary package
- latest news
- current result/context
- video rail
- magazine feature
- community/trending thread module
- newsletter/member CTA
- footer

### Article
- category
- headline/deck
- byline/date
- hero/caption/credit
- readable story column
- save/follow
- related coverage
- discussion bridge
- audio/video companion where relevant

### GatorBait TV
- live/current hero
- show rails
- latest episodes
- clips
- watchlist
- podcast/listen destinations
- social/video embeds

### Magazine
- interactive current cover
- cover lines
- issue contents
- features
- galleries
- archive covers
- audio/video companions

### GatorBait.net
- board index
- trending discussions
- game-day thread emphasis
- thread page
- member/profile states
- story-to-thread linking

### Recruiting
- latest recruiting stories
- commitment/visit content where verified
- discussion bridge
- no invented rankings/data

## Motion hierarchy

Tier 1 native:
- section reveals
- image scale/crop transitions
- nav/drawer movement
- rails
- sticky progress
- hover/focus emphasis

Tier 2 advanced only when justified:
- parallax depth
- magazine cover choreography
- Rive animation
- limited GSAP sequences

No motion may be required for content comprehension.
