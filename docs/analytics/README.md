# Traffic snapshots (Wix Analytics)

Wix keeps only about 61 days of daily traffic, so older numbers disappear. This folder keeps snapshots so design changes can be compared with traffic later.

- `wix-daily-traffic-2026-09-03_to_2026-11-02.csv`: daily sessions and unique visitors, Sept. 3 to Nov. 2, 2026 (from the Wix Analytics API; sales are omitted here on purpose).

## Reading it (Nov. 3, 2026)

Game results, not page design, explain the big days: Sept. 26-27 (Ole Miss win), Oct. 17-18 (Texas win), Oct. 31 and Nov. 2 (Georgia and the basketball opener). Ordinary Tue-Thu weeks run about 280 to 840 sessions a day, with the lowest week Oct. 20-22 (open date). Design changes in the log (Gazette restore Oct. 18, light homepage Oct. 31) cannot be separated from the schedule. To test a design change, change one section only and compare it with the others for two weeks.
