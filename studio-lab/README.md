# GatorBait Studio UI Lab

This is the upstream-first reference lab requested by the owner. It intentionally follows the modern UI stack used/recommended by the selected upstream projects so we can run and evaluate patterns before promoting them into Wix Studio.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Important

- This is NOT production.
- The existing Wix Studio wireframe remains the target implementation.
- Do not point the GatorBait domain here.
- Do not migrate members/business data here.
- Mine successful patterns and then wire them into the Studio product.
