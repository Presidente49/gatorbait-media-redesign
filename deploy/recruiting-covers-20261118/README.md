# Recruiting series cards (Nov. 18, 2026)

Typeset GatorBait series cards for the Recruiting Desk, built to match the Nov. 16 "Recruiting Notebook" card (1920x1080, navy, Gator orange and blue shapes, Barlow ExtraBold). `card.py` renders a card from a kicker, title lines and a sub line. Credit line on the site: "Graphic: GatorBait Media". No recruit photos.

`recruiting-report-series-card-1920x1080.jpg` replaces the Rivals-watermarked cover on the Nov. 18 Recruiting Report (post 18a50b93), whose source and permission could not be confirmed.

Barlow TTFs: github.com/google/fonts, ofl/barlow (SIL Open Font License). Place them in a `fonts/` folder beside `card.py` to run it.
